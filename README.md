# dev-ready-container

A reusable **Dev Container** setup to quickly start building almost any app.

## What's included

This project uses the Microsoft universal dev container image, which comes with
common development tools and runtimes preinstalled (for example Node.js, Python,
Go, Java, .NET, Rust, and common build utilities).

## Usage

1. Open this repository in VS Code.
2. Install the **Dev Containers** extension.
3. Run **Dev Containers: Reopen in Container**.

After the container starts, you can scaffold and build your app using the stack
you choose.
